
# PhishGuard – Cybersecurity Awareness Website

## Project Overview

PhishGuard is a cybersecurity awareness and educational website designed to teach users how to recognize phishing attacks and practice safer online behaviour.

The project provides interactive learning activities that help users understand common phishing techniques, identify suspicious messages, and inspect website addresses.

## Project Objectives

- Educate users about phishing attacks.
- Explain common phishing techniques.
- Promote safe browsing habits.
- Teach users how to identify suspicious emails and URLs.
- Provide interactive cybersecurity awareness exercises.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Website styling and layout.
- JavaScript – Interactive features and functionality.
- LocalStorage – Saving learning progress in the browser.

## Features

### 1. Home Page
Introduces PhishGuard and its cybersecurity awareness objectives.

### 2. About Phishing
Explains phishing and common phishing techniques.

### 3. Threat Awareness
Introduces different phishing threats, including email phishing, spear phishing and smishing.

### 4. Protection Tips
Provides practical recommendations for staying safe online.

### 5. Awareness Quiz
An interactive quiz that tests users' understanding of phishing and cybersecurity awareness.

### 6. Email Awareness Lab
Uses a fictional email example to teach users how to recognize phishing warning signs.

### 7. URL Inspection Lab
Provides fictional and educational URL examples to help users understand suspicious website addresses.

### 8. Awareness Dashboard
Tracks quiz results, email analysis activity, URL inspections and overall learning progress.

### 9. Reset Progress
Allows users to clear their locally saved learning progress.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.

## Ethical Use

PhishGuard is designed strictly for cybersecurity education and awareness.

All examples are fictional and intended to demonstrate phishing warning signs. The project does not collect passwords, personal information or user credentials.
